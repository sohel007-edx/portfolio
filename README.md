# 🍥 Sohel Khan — Shinobi Game Developer Portfolio

An interactive, high-energy **Naruto-themed portfolio website** for **Sohel Khan**, 19-year-old B.Tech CSE Core student at JECRC University, aspiring Game Developer, Football Striker (#10), and Multi-Game Virtuoso.

---

## 🥷 Live Features & Highlights

1. **Naruto Shinobi Aesthetics**:
   - Leaf Village (*Will of Fire* Orange & Onyx), *Sharingan* (Blood Crimson), and *Sage Mode* (Rasengan Cyan) real-time theme switchers.
   - Interactive Kunai mouse cursor with trailing chakra aura.
   - Dynamic floating chakra particles and falling leaf petals on HTML5 Canvas.
   - Authentic Konoha Shinobi Registration ID Card with **3D perspective tilt** on mouse hover.

2. **Gamer & Footballer Heritage**:
   - **The #10 Striker Arena**: Interactive Football pitch showing Sohel's spatial awareness, agility, and how real-world football kinematics translate into game engine physics.
   - **"I Can Play Almost Every Game"**: Breakdown of genres (Sports, FPS, Fighting, RPGs, Simulators) and why deep gaming intuition creates better game systems.

3. **Game Development Arsenal (Jutsu Matrix)**:
   - **Kekkei Genkai**: Unity 3D (C#), Unreal Engine 5 (C++/Blueprints), Blender 3D, HTML5 Canvas.
   - **Ninjutsu (CS Core)**: C++, Object-Oriented Programming, Data Structures & Algorithms, Python.
   - **Taijutsu**: Rigidbody Physics, Hitboxes, A* Pathfinding, Game Loop Optimization.

4. **Scroll of Missions (Game Projects Showcase)**:
   - Filterable missions by rank (S-Rank, A-Rank, B-Rank).
   - Interactive modal inspection popups with architecture breakdowns, tech stacks, and key takeaways for 6 distinct game prototypes.

5. **🎮 Playable In-Browser Mini-Game: "Chunin Exam Dash"**:
   - Fully functional 2D arcade canvas game.
   - Controls: Keyboard (`Arrow Keys` / `WASD` / `Space`) or **Mobile Touchpad Buttons**.
   - Collect 🌀 Chakra Orbs and ⚽ Footballs, dodge falling 🗡️ Kunai.
   - Charge Chakra meter to 100% to unleash **Rasengan Burst**!
   - Saves High Scores to `localStorage`.

6. **Web Audio Synthesizer**:
   - Built-in procedural sound effects (Kunai clash, Chakra sweeps, Rasengan detonations, arcade chimes) using the browser's native Web Audio API — **zero external audio file dependencies**!
   - Full mute / sound toggle button.

7. **Kuchiyose no Jutsu (Summoning Scroll Contact Form)**:
   - Ninja scroll UI with wooden roller edges.
   - Interactive hand sign selector (Tiger, Dragon, Snake, Ram).
   - Direct dispatches for internships, game dev collaborations, and tournaments.

## 🌐 Free One-Click Deployment to GitHub Pages
1. Create a new GitHub repository named `sohel-khan-portfolio`.
2. Push `index.html`, `styles.css`, and `script.js` to `main`.
3. Go to **Settings** > **Pages** > Select Branch `main` > Save.
4. Your website is live worldwide at `https://<username>.github.io/sohel-khan-portfolio`!
